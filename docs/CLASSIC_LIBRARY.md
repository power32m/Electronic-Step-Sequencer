# Classic library / 经典曲库

[Online app / 在线体验](https://op16-field-sequencer.breezysquid.chatgpt.site/) · [English guide](USER_GUIDE.en.md) · [中文指南](USER_GUIDE.md)

Complete MIDI arrangements at their source tempos, with the original timeline through the final note. These are synthesized adaptations of fan arrangements, not original soundtrack recordings. Repeated sections already present in each MIDI are retained; the old bar-32 cutoff is removed. Six-part curation still omits doubled orchestral and echo layers as documented below.

六首曲目保留原 MIDI 时间线，补齐第32小节之后的全部已选声部音符，保留文件原有重复段落。完整版指所列 MIDI 的完整六声部改编，不是游戏原声录音；不额外拼接循环。空白工程仍以32小节为上限，经典曲目可完整播放、保存、编辑和导出。

Untouched old 32-bar autosaves upgrade to the complete arrangement while retaining mixer settings. Edited excerpts stay intact; Load Full Arrangement explicitly replaces them with the full score. Download a project backup before replacing a personal edit.

Super C uses melody tracks 1/2, bass 8 and drums 10; doubled orchestral layers are omitted. Double Dragon II uses melody 2, counterline 4, bass 1 and drums 5; echo track 3 is omitted. Jackal uses tracks 1/2/3; doubled tracks 5/6/7 are omitted and the source has no separate drum part. Castlevania uses tracks 1/2/3/6; echo tracks 4/5 are omitted. River City Ransom uses melody tracks 2/3, bass 1 and drums 4. Super Mario Bros. uses melody 1, countermelody 2, bass 3 and percussion 4. Both retain all note-bearing tracks. River City Ransom bass notes down to A0 (MIDI 21) are preserved; the editor now includes that low range. Source track numbers are zero-based.

The Super C index does not name its sequencer; no attribution is invented. The Jackal file credits Stevenm9 and Keio. Music and game rights remain with their respective owners. MIDI availability does not grant redistribution or commercial music rights.
