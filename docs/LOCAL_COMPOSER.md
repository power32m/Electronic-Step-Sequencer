# Local accompaniment / 本地伴奏

Version **2.3.1 · 2026-10-18**. The public Windows ZIP remains v2.2.2; current source and the local Windows build include this feature.

## English

In a **new blank project**, choose a style and click Random Accompaniment. Generation runs on the device, without an account, composition API or model download. The browser must first load the app. Undo/Redo restores the complete arrangement, including harmony and generation history.

- Seven styles provide separate drum anchors, bass rhythms, chord rhythms and six diatonic phrase grammars each. Four-bar harmonic ideas repeat or answer one another in longer projects.
- Automatic bars receive a new progression. Changing a bar's chord selector protects that bar's degree on subsequent generations. Older saved projects without harmony metadata preserve all existing degrees; start a new blank project to explore automatic harmony.
- Held lead notes and strong beats influence harmonic selection. Dense lead parts reduce harmony density and strength. Lead notes, key/scale, tempo, swing and all mixer settings are preserved.
- Harmony uses explicit chord notes: close-position inversions, block chords, split voicings or arpeggios, chosen by style. Hip-hop can sustain pads; FC stays monophonic. The piano roll, three keyboards and WAV render the same notes.
- Bass follows chord roots and kick accents; weak beats can connect chords. Two-bar rhythmic themes develop over phrases. Loop tails retain activity, with large bass jumps across the loop penalized.
- Six arrangements are ranked for density, voice coordination, melody clashes and similarity to the preceding arrangement. Up to six recent harmonic progressions are saved to discourage repeats. Repetition may remain necessary with fixed harmony or a strongly constraining melody.

The button replaces existing drum, bass and harmony **notes**, including manual note edits; protected chord **degrees** are retained. Save important work first. This is a local rule-based composer, not a trained neural model or audio-to-chord system. Heuristic scores do not guarantee a pleasing result; audition and edit the result. Existing classic scores cannot be overwritten by this button.

## 简体中文

**新建空白工程**后，选风格、点“随机伴奏”即可。无需账号、作曲API或模型下载；网页版需要先加载程序资源。撤销、重做会恢复完整编排，包括和弦及生成记录。

- 七种风格分别配置鼓组重拍、贝斯节奏、和弦节奏，以及各六组调内和声乐句。较长工程让四小节和声主题重复或形成回应。
- 自动小节会获得新的和弦走向。手动修改某小节的和弦选择后，后续生成保留该小节的级数。没有新和声记录的旧工程默认保留全部和弦；体验自动和声请新建空白工程。
- 主旋律的长音和强拍影响和弦选择，旋律密集时降低和声密度与力度。主旋律音符、调性、速度、摇摆与全部混音设置保留。
- 和声使用真实独立音符，按风格选择转位、齐奏、分组或分解演奏；嘻哈可使用持续铺底，FC保持单音。钢琴卷帘、三层键盘和WAV使用同一组音符。
- 贝斯呼应和弦根音与底鼓，弱拍少量使用连接音；两小节节奏主题随段落发展。末尾保留循环律动，筛选时减少回到开头的大幅贝斯跳跃。
- 每次比较六套编排，检查密度、声部配合、旋律冲突与上一版的相似程度，并保存最近最多六组和弦走向以减少重复。手动和弦或旋律限制较强时，部分重复仍属合理。

生成会替换已有鼓组、贝斯、和声音符，包括手工音符修改；受到保护的是手动指定的和弦级数。重要内容请先保存。这是规则驱动的本地编曲器，并非训练好的神经音乐模型，也不支持从音频识别和弦。规则评分不能保证每次都好听，请试听后选用或修改。经典曲目无法被此按钮覆盖。
