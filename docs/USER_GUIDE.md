# OP·16 使用指南

## 🌐 [打开网页版](https://op16-field-sequencer.breezysquid.chatgpt.site/)

适用版本：2.2.2，2026-10-17更新版。Windows安装、离线使用及数据目录见[桌面版说明](WINDOWS.md)。

版本及交付范围见[更新记录](../CHANGELOG.md)和[Windows版状态](WINDOWS.md)。本地维护保留自动保存和个人工程；网页与桌面之间仍需用JSON文件迁移作品。

## 1. 播放与定位

首次启动默认载入“赤影战士”，后续可恢复自动保存。顶部选曲，点击“播放”启用声音，再次点击暂停，“继续”接着播放。暂停保留声音时钟与音符尾音状态。

| 控件 | 用法 |
| --- | --- |
| 小节输入框 | 输入小节号并回车；播放中定位后继续，暂停时定位后点击播放 |
| 从第N小节播放 | 从当前编辑小节开头重新播放 |
| 回到开头 | 停止并回到第1小节 |
| 四小节分页 | 箭头切换分组，点击小节卡片选择编辑位置 |
| 跟随播放 | 默认勾选；手动选小节或音符后停止跟随，重新勾选恢复 |

下滑后播放栏收紧并固定在顶部。空格播放／暂停，在文字或数值输入框中输入时不会触发快捷键。

## 2. 三层键盘与视角

![三层键盘及颜色图例](images/instrument-current.png)

| 层 | 声部 | 颜色 |
| --- | --- | --- |
| 上层 | 主旋律 | 橙色 |
| 中层 | 独立副旋律或三和弦 | 绿色 |
| 下层 | 贝斯 | 蓝色 |

三层同时反馈，无需切换声部，各层按全曲适配音域。和弦同时点亮组成音，点击某层琴键直接使用该声部音色试听。静音或被其他独奏声部排除的轨道不亮键。显示屏曲线是节拍示意，不是音频波形测量。

默认“俯视2D”固定旋转和缩放；“立体3D”允许拖动旋转、滚轮缩放和自动旋转。“↺”返回默认固定俯视。拖动模型的声音旋钮也可调整参数。图例位于键盘下方，与轨道颜色对应。

| 洛克人Ⅱ | 113 | 180 |

| 最终幻想6 | 110 | 205 |
曲目支持完整播放、编辑和导出，来源见[曲库说明](CLASSIC_LIBRARY.md)。重新选择预设会替换当前工程，重要修改请先保存JSON；替换可撤销。

点击播放下方的“空白工程”，创建4小节空工程。修改“工程小节”或点击“＋ 小节”，可调整为1–32小节。缩短会移除末尾小节，撤销可恢复；增减同时更新默认导出长度。经典案例保留完整原谱长度，不受空白工程32小节上限截断。

未修改过的旧32小节案例会补齐为完整版；修改过的工程保留原样，可用提示中的“载入完整版”明确替换。

## 4. 伴奏、旋律与调性

空白工程中选择流行、摇滚、放克、电子舞曲、嘻哈、拉丁、FC芯片或随机风格，再点击“随机伴奏”。它为全工程生成鼓组、贝斯与和弦，保留主旋律、和弦走向、速度和混音设置。反复点击获得变化，支持撤销。经典曲目中按钮禁用。FC芯片风格使用三角波贝斯与方波和弦。

“生成旋律”替换整个工程的主旋律，保留其他轨；“旋律变奏”改动部分音高，“节奏变奏”调整少量步骤。均使用本地规则，不调用AI音乐服务。

改变主音或音阶会转调现有音符。音阶约束使新输入吸附到当前音阶；Boss包含半音经过句，保留原谱时应关闭约束。普通和弦模式修改每小节和弦级数，可联动该小节和弦与贝斯；独立副旋律模式不显示和弦级数。

## 5. 六轨与音符编辑

![当前六轨及钢琴卷帘](images/composer-current.png)

底鼓、军鼓、踩镲、贝斯、主旋律和副旋律／和弦六轨，每小节16步。M静音，S独奏，静音优先。音色、音量和M/S在各轨按列对齐；上方旋钮控制速度、摇摆、滤波与主音量。

点击步骤格开关并选中，右键只选中。下方调整力度、音高／根音和音长。1步为十六分音符，4步为一拍，音长最多32步。

选中贝斯、主旋律或第六轨后，钢琴卷帘支持：

- 点击空白处写入，拖动音符改音高或起点。
- 拖右端改长度，右键、Delete或Backspace删除。
- 步内连奏和三连音独立选择、编辑。
- 普通三和弦的三个组成音共同移动，不能在此模式任意增删内部单音。

四小节分页下方提供复制、粘贴、清空和节奏变奏。复制／粘贴作用于当前小节六轨，清空只关闭当前小节音符。Ctrl+Z撤销、Ctrl+Y重做，最多80个历史状态。

## 6. 保存、打开与迁移

“保存工程”下载 `.op16.json`；“打开工程”读入v1/v2/v3格式。网页版及更新后的Windows版上限均为4MB，支持约1.7MB的洛克人Ⅱ113小节完整工程。

自动保存仅属于当前浏览器或桌面配置，不在设备、浏览器、网页版与桌面版之间同步。迁移时保存JSON，再在另一端打开；清理浏览器数据前也应备份。“恢复旧版工程”可读取旧v1/v2自动保存，会替换当前工作区，支持撤销。

## 7. WAV导出

选择小节数后点击“导出音频”。经典曲目支持完整长度，空白工程最多32小节；按当前乐句循环导出。格式为44.1kHz、16-bit、立体声，另留1.8秒尾音。Boss默认24小节导出40.2秒。

进度分准备声部、合成立体声、写入WAV。长曲需要等待；“取消”放弃本次导出并保留工程。浏览器原生离线渲染可能继续到结束，但取消后不会下载结果。导出使用点击时的工程快照，期间编辑不改变该次内容。

网页版通过浏览器下载，桌面版弹出保存对话框。桌面最小化可继续播放、暂停3D绘制；系统休眠、设备切换和后台策略可能影响播放。

## 常见问题

- **没有声音：** 先点击播放，检查主音量、M/S和系统输出设备，尝试暂停续播或回到开头。
- **随机伴奏不能点：** 先新建空白工程，经典曲目不能直接使用此操作。
- **2D不能拖动缩放：** 固定视图便于点键，切换3D即可调整视角。
- **找不到上次作品：** 确认使用同一浏览器配置或桌面程序，两端不共享自动保存。
- **怎样导入MIDI：** 当前仅内置曲库，不支持通用MIDI导入／输出。
