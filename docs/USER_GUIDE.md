# 使用指南

## 🌐 [打开网页版](https://op16-field-sequencer.breezysquid.chatgpt.site/)

1. 点击“播放”启用声音，空格键可以启停；输入文字时空格不会触发播放。
2. 初始Boss案例有24小节，每页显示四小节，左右箭头翻页。播放默认跟随进度，手动选择后可停在指定小节编辑。
3. 六轨右侧的M为静音，S为独奏。第六轨在Boss案例中是独立副旋律，其他音乐预设中可以是三和弦。

## 编辑音符

点击步骤格开关音符并选中，右键只选中。下方调整力度、音高与音长。1步为十六分音符，4步为一拍，最大音长32步。

选中贝斯、主旋律或第六轨后显示钢琴卷帘：点击空白处创建音符；拖动改变音高或位置；拖右端改变长短；右键、Delete或Backspace删除。普通三和弦内的三个音共同移动。

复制和粘贴操作当前小节的六轨内容，清空只关闭当前小节。Ctrl+Z撤销，Ctrl+Y重做，最多保留80个状态。

## 调性与音色

改变主音或音阶会同步转调现有旋律；开启音阶约束后，输入会吸附到当前音阶。Boss原谱含半音经过句，想保持原貌时请关闭约束。

音色选择、声部音量及速度、Swing、滤波和主音量旋钮都可调整。Boss案例使用方波和三角波；其他预设还包括电钢琴、拨弦、柔和合成音和铺底。

生成旋律会替换当前完整乐句的主旋律；旋律变奏改动部分音高，节奏变奏改动少量步骤。重新选择原始预设即可返回案例。

## 3D乐器

拖动旋转、滚轮缩放，也可使用俯视、自动旋转、结构拆解、外壳透视与配色按钮。点击实体琴键可以试听，拖动实体旋钮可以调整声音参数。

选择3D键盘试听声部和八度，可以观察对应声部的播放反馈。超出当前琴键范围的音符仍然播放；显示曲线是节拍示意。

## 保存与导出

自动保存位于当前浏览器，请定期点击“保存工程”下载 `.op16.json` 文件。“打开工程”可读入v1、v2和v3格式；旧工程的原音符保留。

WAV导出支持1–32小节，按当前完整乐句循环，格式为44.1kHz、16-bit、立体声，另留1.8秒尾音。Boss默认24小节导出约40.2秒。生成音频需要等待，完成后浏览器下载文件。

切勿将自动保存当作唯一备份。网页版不跨设备同步，也没有后台云端工程库。后台播放与移动端行为受系统和浏览器限制。


## 工程小节与经典曲库

播放下方的“空白工程”按钮创建四小节空工程。修改“工程小节”数值或点击“＋ 小节”，可调整为1–32小节；到32小节时增加按钮停用。缩短会移除末尾小节，撤销可恢复。增减小节数同时更新默认导出长度。四首新增经典曲目均为32小节选段，赤影战士默认案例保持24小节。

钢琴卷帘保留步骤内部的三连音与连奏，每个音符可单独选择、修改和删除。
