# 使用指南

## 🌐 [打开网页版](https://op16-field-sequencer.breezysquid.chatgpt.site/)

1. 顶部播放栏可选曲，点击“播放”启用声音，空格键播放/暂停；暂停保留当前位置与正在发声的尾音，点击“继续”接着播放。输入文字时空格不会触发播放。
2. 初始Boss案例有24小节，每页显示四小节，左右箭头翻页。播放默认跟随进度，手动选择后可停在指定小节编辑。
3. 六轨右侧的M为静音，S为独奏。第六轨在Boss案例中是独立副旋律，其他音乐预设中可以是三和弦。

在顶部输入小节号并回车可定位；播放中定位会跳到该小节继续，暂停时定位后可点击播放。“从第N小节播放”从当前编辑小节重新开始，“回到开头”停止并回到第1小节。滚动编曲时，播放栏缩为紧凑布局并固定在顶部。

## 编辑音符

点击步骤格开关音符并选中，右键只选中。下方调整力度、音高与音长。1步为十六分音符，4步为一拍，最大音长32步。

选中贝斯、主旋律或第六轨后显示钢琴卷帘：点击空白处创建音符；拖动改变音高或位置；拖右端改变长短；右键、Delete或Backspace删除。普通三和弦内的三个音共同移动。

复制和粘贴操作当前小节的六轨内容，清空只关闭当前小节。Ctrl+Z撤销，Ctrl+Y重做，最多保留80个状态。

## 调性与音色

改变主音或音阶会同步转调现有旋律；开启音阶约束后，输入会吸附到当前音阶。Boss原谱含半音经过句，想保持原貌时请关闭约束。

音色选择、声部音量及速度、Swing、滤波和主音量旋钮都可调整。Boss案例使用方波和三角波；其他预设还包括电钢琴、拨弦、柔和合成音和铺底。

生成旋律会替换当前完整乐句的主旋律；旋律变奏改动部分音高，节奏变奏改动少量步骤。重新选择原始预设即可返回案例。

## 3D乐器

拖动旋转、滚轮缩放，也可使用俯视、自动旋转与恢复视角按钮。点击实体琴键可以试听，拖动实体旋钮可以调整声音参数。

三层键盘由上至下分别显示主旋律、副旋律／和弦、贝斯，使用橙、绿、蓝三种颜色同步反馈，无需切换声部。每层根据整首曲谱自动适配音域；和弦同时点亮组成音。点击某层琴键，直接使用该层声部音色试听。静音或被其他声部独奏排除的声部不亮键。显示曲线是节拍示意。

## 保存与导出

自动保存位于当前浏览器，请定期点击“保存工程”下载 `.op16.json` 文件。“打开工程”可读入v1、v2和v3格式；旧工程的原音符保留。

空白工程WAV导出支持1–32小节，经典曲目支持导出完整长度，按当前完整乐句循环，格式为44.1kHz、16-bit、立体声，另留1.8秒尾音。Boss默认24小节导出约40.2秒。导出显示准备声部、合成立体声、写入WAV三个阶段的进度；点击“取消”可中止本次导出，工程保留。声音在后台线程计算，完成后浏览器下载文件。

切勿将自动保存当作唯一备份。网页版不跨设备同步，也没有后台云端工程库。后台播放与移动端行为受系统和浏览器限制。


## 工程小节与经典曲库

播放下方的“空白工程”按钮创建四小节空工程。修改“工程小节”数值或点击“＋ 小节”，可调整为1–32小节；到32小节时增加按钮停用。缩短会移除末尾小节，撤销可恢复。增减小节数同时更新默认导出长度。六首经典曲目分别为74、44、35、48、88、37小节，可完整播放、编辑和导出；赤影战士默认案例保持24小节。未修改过的旧32小节案例自动升级，修改过的工程保留原样，可点击“载入完整版”重新加载。

钢琴卷帘保留步骤内部的三连音与连奏，每个音符可单独选择、修改和删除。

俯视2D模式锁定旋转角度，便于点击琴键；滚轮仍可缩放。切换立体3D后可拖动旋转。
